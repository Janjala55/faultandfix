GE Dishwasher Blinking Start Light & Won’t Start: CSM Tripped Reset & Door Latch Test

By admin
Updated: Oct 13, 2026
Reviewed by Dan Miller (Master Appliance Tech)
4 min read
Verified Fault Diagnostic Blinking Start / 888
Verified by GE Service Bulletin DD01-19 / Pub 31-9233
Official Fault Meaning: Door Interlock Not Detected / Current Sense Module (CSM) Protective Trip
Most Likely Cause: Door latch microswitches failed continuity check, warped tub strike, or CSM tripped due to heating element short.
Repair Difficulty: Intermediate DIY
Estimated Time: 25–35 minutes
Required Tools: 1/4" nut driver, T15 Torx driver, digital multimeter
Applicable Models: GE GDF510, GDF520, GDF640, GDT655, GDT695, Profile PDT715 series
Immediate Safe Action / Quick Reset

Consumer Error Mode Reset: Press and hold START and SELECT CYCLE together for 5 seconds until all LEDs light up. Press START to view error history. If Start blinks rapidly, latch microswitch is open; test continuity on switch terminals.

A flashing green or amber START light on a GE dishwasher accompanied by three intermittent beeps is one of the most frustrating appliance failures. Homeowners press Start, shut the stainless steel door, and expect the wash cycle to begin; instead, the machine remains totally dead or beeps continuously with the Start button blinking. This symptom is caused by either a failed Door Latch Microswitch Assembly or an activated Current Sense Module (CSM) on the main electronic control board.

Step 1: Enter GE Consumer Error Diagnostic Mode

Modern GE dishwashers feature a built-in field diagnostic routine that pinpoints the root cause in under 1 minute without removing any panels:

  1. Ensure the dishwasher door is closed and latched.
  2. Press and hold the SELECT CYCLE and START keypad buttons simultaneously for 5 seconds.
  3. All console status LEDs will illuminate steadily, confirming the unit is in Consumer Error Mode.
  4. Observe the START light:
    • Start Light Flashing Rapidly: The main control board does not sense that the door is closed. The door latch microswitch is mechanically stuck open or electrically disconnected.
    • Start Light Solid: The door switch is closed and recognized properly. Proceed to CSM diagnostic check.
  5. To exit error mode, press SELECT CYCLE and START simultaneously for 5 seconds or wait 10 minutes for auto-timeout.

Step 2: Multimeter Test on GE Door Latch Microswitches

The GE door latch assembly mounted at the top center of the door contains two miniature snap-action microswitches wired in series. If either switch suffers pitted silver contacts, the dishwasher will never initiate a cycle.

⚠️ 120V AC Electrical Shock Hazard

Turn off the circuit breaker supplying power to the dishwasher before removing the inner or outer door screws. High voltage is present at the door latch terminals.

  1. Open the dishwasher door and use a T15 Torx driver or 1/4″ nut driver to remove the upper perimeter screws on the inner stainless door liner.
  2. Carefully support the outer door panel as it drops forward.
  3. Locate the black plastic latch assembly at the very top center of the door frame.
  4. Disconnect the two electrical spade connectors from the microswitch terminals.
  5. Set your digital multimeter to Continuity / Resistance (Ω):
    • Latch Lever UNPRESSED (Door Open): Meter must read Infinite (O.L.).
    • Latch Lever PRESSED IN (Door Closed): Meter must read 0.0 Ω to 0.4 Ω (Continuous).
  6. If the meter reads open (O.L.) when the latch is manually depressed, the microswitch has failed. Replace door latch part #WD21X10490.

Step 3: Resetting the Tripped Current Sense Module (CSM)

If the door latch is verified good, but the dishwasher is completely unresponsive, the main control board’s Current Sense Module (CSM) has tripped. The CSM is a factory safety protection circuit that permanently kills 120V power to the machine if current leakage to ground exceeds 20mA (typically triggered by a damaged calrod heating element or circulation pump winding).

  • Locate the main electronic control board housed in the galvanized steel junction box underneath the tub on the right side.
  • Look at the green status LED on the control board:
    • Solid Green: Board is healthy and waiting for command.
    • 1 Flash every 3 seconds: Dishwasher in delay start or waiting for cycle start.
    • Completely OFF while 120V supplied: The CSM has permanently tripped.
  • Before replacing the main board (#WD21X24900), test the heating element resistance with your multimeter (OEM Spec: 16 Ω to 22 Ω). If the element is cracked or reads open/grounded, replace both the heating element and the main control board.

OEM Replacement Part Information

OEM Genuine GE Appliances Component

GE Dishwasher Door Latch Switch Assembly

OEM Part Number: WD21X10490 (Replaces WD21X10433, AP5668411, PS6447681)

Compatibility: Fits GE GDF510, GDF520, GDF540, GDF640, GDT580, GDT655, GDT695, and Profile PDT715 dishwasher series.

Installation Time: 20 minutes with a T15 Torx driver.

Frequently Asked Questions

Why does the Start light flash after I open the door to add a dish?

On modern GE dishwashers, whenever the door is opened mid-cycle, the cycle automatically pauses. You must press the START button firmly and close the door within 4 seconds; otherwise, the Start light blinks and the cycle will not resume.

Can a sagging upper dish rack prevent the door from latching?

Yes. If the upper rack spray arm water feed tube at the back of the rack does not align with the tub water manifold, the rack sticks out 1/4 inch, preventing the door strike from engaging the microswitches fully.
