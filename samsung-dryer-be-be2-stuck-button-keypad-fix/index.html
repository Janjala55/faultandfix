Samsung Dryer bE / bE2 Error Code: Stuck Button & Touch Panel Repair

By Fault and Fix Diagnostic Engineering Team
Updated: Nov 18, 2026
OEM Verified
Fault Code: bE / bE2 / 6E Reviewed by Master Appliance Technician
What It Means: Keypad Button Continuous Short / Stuck Key (Central microprocessor detects a user touch key held closed continuously for more than 30 seconds)
Most Likely Root Cause: A mechanical plastic button tab jammed in depressed position or moisture/corrosion shorting the capacitive touch membrane trace on user interface sub-PCB.
Repair Difficulty: Beginner to Intermediate DIY
Estimated Time: 20–30 minutes
Required Tools: Phillips screwdriver, isopropyl alcohol 90%+, microfiber swab, plastic pry tool
Applicable Models: Samsung DVE50M7400, DVE54R7200, DVG45R6100, DVE45T6000 series
Immediate Safe Action / 60-Second Quick Check

Run your thumb firmly across all console buttons from left to right. Rapidly tap each button 10 times to dislodge any stuck plastic edge.

1. Symptoms & Operational Failure Signs

When code bE / bE2 / 6E triggers, the appliance controller detects abnormal electrical feedback or physical boundary limits out of range. Check for these real-world failure symptoms:

  • Dryer beeps incessantly when plugged in and flashes error code 'bE' or 'bE2'.
  • Control panel is completely unresponsive to finger presses on Start or Cycle knobs.
  • Dryer turns on spontaneously and initiates unwanted cycles.
  • Display digits flicker or cycle continuously through menu options.

2. The 30-Second Hard Reset Sequence

Clear temporary software glitches, parasitic capacitive voltage, and transient relay lockouts with this manufacturer capacitive discharge sequence:

  1. Unplug dryer power cord from wall outlet for 5 minutes.
  2. While unplugged, press and hold the Power button for 10 seconds to drain capacitive charge.
  3. Inspect physical touch buttons around Start, Temp, and Dry Level for debris or sticky spills.
  4. Plug cord back in and observe whether control boots to normal idle screen.

3. Entering Hidden Factory Diagnostic Mode

Execute this authorized technician button cadence to retrieve stored historical error logs and force individual component actuation tests:

  1. Enter diagnostic test mode: Press 'Dry Level' and 'Time' together for 7 seconds.
  2. Audible chime confirms test mode. Look at digital display: code 'bE2' indicates sub-PCB fault.
  3. Press each button individually: display will beep and show unique button identification number.
  4. If display beeps continuously without touching buttons, touch matrix is defective.

5. Step-by-Step Mechanical Tear-Down & Repair

Follow these 5 OEM service manual steps to access, inspect, and replace the failing component safely:

  1. Disconnect Power: Unplug dryer from 240V/120V wall receptacle.
  2. Remove Console Rear Cover: Remove 4 Phillips screws holding the sheet metal cover behind the top front control console.
  3. Unclip UI Sub-Board: Disconnect multi-pin ribbon cables linking display board to main power PCB.
  4. Clean Ribbon Contacts: Release ribbon connector zero-insertion-force (ZIF) lock. Clean gold ribbon contacts with 90%+ isopropyl alcohol on a lint-free swab.
  5. Re-Seat or Replace Board: If individual capacitive switch remains stuck closed, replace user interface display board (DC92-01626A / DC92-02144A) and reassemble.

6. Frequently Asked Questions

Can cleaning spray cause code bE2 on Samsung dryers?

Yes. Spraying liquid glass cleaner directly onto the front control panel allows liquid to seep behind the plastic bezel, bridging the sensitive capacitive touch traces and triggering code bE2 within minutes.

What is the difference between bE and bE2?

Error bE indicates a general stuck button on the main keypad matrix, while bE2 specifically indicates an internal communication or short-circuit error within the user interface sub-microprocessor.
